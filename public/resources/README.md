# 资源文件夹

这个文件夹用于存放博客中分享的各类资源文件，包括：

- `reports/` - 实验报告
- `study/` - 复习资料
- `exam/` - 考试相关资料
- `templates/` - 各类模板文件

## 使用方法

1. 将你的文件放入对应的子目录
2. 在 `src/content/resources.md` 中添加链接
3. 链接格式：`[文件名](/resources/子目录/文件名.扩展名)`

## 示例

```markdown
[数据结构复习笔记.pdf](/resources/study/data-structure-review.pdf)
```

## 注意事项

- 文件名建议使用英文或拼音，避免中文字符
- 注意文件大小，建议单个文件不超过 10MB
- 对于大文件，可以考虑使用云存储服务并提供外链
